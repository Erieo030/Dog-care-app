目前樣本顯示 reranker 能把這批題目標註的目標段落排到第一名；題目由專案端自撰，數量小、措辭也可能貼近文件，不能據此推論真實使用者問題的命中率或醫療可靠性。

## Context 附加門檻觀察

RRF + reranker top score 以 dev 12 題（9 answerable、3 NONE）選得暫定門檻 `0.365425`。在 dev 本身為 TP=9、FN=0、TN=3、FP=0；套到 test 12 題為 TP=8、FN=1、TN=3、FP=0。漏掉的正例是「常去寄宿和狗公園，非核心疫苗要不要考慮？」（分數 `0.259638`）。

這個門檻只決定是否附加 RAG 知識段落，不會拒絕或阻止一般 AI 對話。小型題集的單一漏例足以說明目前不能將此門檻當成可靠的產品設定；上線前仍要擴大、盲測並評估漏附知識段落的風險。

## 引用與生成抽查

使用三個 test 問題，將各自人工標註的目標段落作為已知證據，交由現有來源約束回答流程生成。三例均回傳可映射至該段來源清單的引用；內容分別涉及台灣狂犬病規範與國際指引區別、美國 CAPC 頻率不可直接套用台灣、以及慢性病飲食變更需先詢問獸醫。無證據案例在本機回傳固定資料不足文字與空引用，沒有呼叫生成模型。

這只檢查格式、引用映射與少數答案是否沿著提供的證據作答；引用存在不等同於每一句都由來源充分支持，也不代表臨床驗證。三篇新文件目前仍是 `clinical_review_status: not_reviewed`。

## 執行與索引狀態

Embedding 服務曾在一個 8 筆批次回傳重複／缺漏的 response index；工具依安全檢查中止，沒有錯配向量。改用 `--embedding-batch-size 4` 後，完整評估成功，程式仍會拒絕不一致索引。

本輪沒有呼叫 MongoDB、寫入 chunks 或切換 active manifest。MongoDB 既有 active index 仍為 13 段；24 段是本機已驗證文件，不是已發布到資料庫的索引。
