# 照護相簿（第一版）

暫時以底部「照片」作獨立入口，頁面標題為照護相簿。照片沿用既有附件，不複製紀錄、圖片或建立社群貼文。

## 範圍與操作

- 目前毛孩、月份與週分組；月份可直接選年／月。
- 全部、健康異常、就醫照片、體重篩選。「健康異常」是健康事件附件，與首頁的日常健康觀察趨勢分開；「就醫照片」指就醫來源的附件，例如藥袋或文件，不代表用藥模組新增照片功能。
- 健康事件縮圖預設遮罩，可用開關顯示或點開大圖。
- 大圖頁顯示日期、來源標題、備註、上傳日期，並開啟原始健康事件／就醫／體重紀錄。
- 刪除與編輯仍從原始紀錄操作；返回相簿後重新查詢。
- 不收錄頭像、未綁定附件或已刪除的來源；沒有生活照片上傳、前後對照、分享或社群。
- 日常便便分類只回傳建議，沒有儲存照片，故不在相簿顯示。不會自動送圖片給 AI。
- 沒有選取毛孩時提示先建立／選擇毛孩；讀取失敗顯示錯誤與重試，不將照片數量誤顯示成 0。
- 月份選擇視窗可捲動，週標題可換行，避免小螢幕／大字體下控制項超出畫面。

## 程式位置

- `CarePhotosScreen.tsx`：頁面組裝、篩選、虛擬化週／照片清單與原始紀錄導航。
- `carePhotoContent.ts`：日期／週分組、來源導航映射與分類。
- `useCarePhotos.ts`：分頁、權限憑證、取消舊請求、重試與資料範圍隔離。
- `components/`：年份／月份選擇、受保護圖片、全螢幕照片詳情。
- `../../services/carePhotoService.ts`：相簿 API。
- 後端 `app/services/care_photo_service.py`：原始紀錄與附件關聯查詢。
- 後端 `app/services/attachment_service.py`：附件 ownership、原圖與按需縮圖。

## API 與資料

- `GET /api/pets/{petId}/care-photos?userId=…&month=YYYY-MM&category=all&limit=50&skip=0`。
- `GET /api/attachments/{attachmentId}/thumbnail?userId=…`：360 像素內 JPEG；不生成永久衍生檔案。
- 所有讀取需登入憑證並驗證毛孩所有權，原圖／縮圖使用相同保護。
- 按紀錄日期而非上傳日期選月份；Mongo naive UTC 先轉台灣時間。
- 原始檔案不修改、不重新上傳；圖片分頁載入，縮圖失敗可重試。

## 驗收

單元測試涵蓋月份邊界、週分組、來源隔離、權限、分頁、取消請求、遮罩、詳情與原始紀錄導航、讀取失敗後重試、圖片憑證更新、晚到圖片重試結果隔離，以及縮圖尺寸／相機方向／損壞圖片處理。當本機 MongoDB 未啟動時，後端可在測試程序用模擬 MongoClient 啟動，其測試資料皆為替身；這不代表真實資料庫已完成串接驗收。

待 iPhone 與實際 MongoDB 驗證：多張照片、較大字體、橫向版面、返回與切分頁、圖片載入失敗、原始紀錄更新／刪除後刷新。
