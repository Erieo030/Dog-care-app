# Reminders feature

- `reminderListContent.ts`: 提醒清單的插圖、狀態文案、日期篩選與分組。
- `components/ReminderListHeader.tsx`：新增按鈕與清單範圍摘要。
- `components/ReminderListCard.tsx`：單筆提醒展示與操作列。
- `components/ReminderListState.tsx`：空白、錯誤、載入狀態。
- `screens/`：後續放提醒清單、建立與編輯畫面。

`ReminderListScreen` 目前保留為既有 navigator route；畫面操作、通知同步與導航行為不變。
