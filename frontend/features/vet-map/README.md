# 臺中動物醫院地圖（第一版）

MEGO 內嵌地圖使用 `react-native-maps`（iOS 預設 Apple 地圖）及按需定位的 `expo-location`。不呼叫 Google Places、地理編碼或路線 API；導航交由系統地圖 App 開啟。拒絕定位仍可瀏覽名單。

## 目前資料範圍

第一版只收錄臺中市政府公開的「夜間／急診動物醫院」名冊 11 家，不代表臺中市完整院所清單。臺中市另有一般動物醫院名冊 282 筆，但來源資料沒有地理座標，因此尚未放上地圖，避免地址轉座標錯誤造成誤導。新增一般院所前，需先確認名冊仍有效、地址與座標吻合，並保留來源和查核日期。

名單共 11 家，其中 10 家顯示已核對地址的標記。永昌動物醫院的定位服務結果回傳「北屯路 266之32號」，與官方「北屯路 32 號」不同，因此移除該筆座標，清單標示「位置待確認」；仍可聯絡及依官方地址導航。

每筆資料分別記錄官方資料頁更新時間、座標來源與查核日期。資料頁的更新時間不等於所有院所當天重新確認營業。服務時間和急診狀態以政府名冊文字呈現，不推論目前是否營業；畫面提醒飼主出發前先電話確認。

## 資料來源與授權

- [臺中市夜間及急診動物醫院名冊（政府資料開放平台）](https://data.gov.tw/dataset/83763)：名冊 11 筆，資料頁標示最近更新 2026-06-15。政府資料開放授權條款第 1 版。
- [臺中市合法動物醫院名冊（政府資料開放平台）](https://data.gov.tw/dataset/83762)：一般院所 282 筆，作為後續擴充來源；目前未納入地圖。
- [OpenStreetMap 著作權與授權](https://www.openstreetmap.org/copyright)：院所座標以地址定位後比對行政區、道路與門牌，畫面標示 `© OpenStreetMap contributors`。地址吻合不代表已經實地勘查；導航採官方地址而非近似標記位置。重新匯出或散布 OSM 衍生資料時，須遵守 ODbL 條款及署名要求。
- [Nominatim 使用政策](https://operations.osmfoundation.org/policies/nominatim/)：本次僅以單執行緒、低於每秒一次的速度做小量維護查核，保留識別 User-Agent 與快取；App 不會呼叫該服務。不得將此流程改成輸入即時查詢或無限制批次定位。
- [永昌官方院所資料](https://www.animal.taichung.gov.tw/1521448/1521543/1521544/1606060)：用於確認門牌差異。

## 維護規則

- 不自行猜測座標、營業狀態或是否接受非舊客戶。
- 官方名冊的來源更新時間與 MEGO 查核日期分開記錄。
- 電話、時段或地址有疑義時先移除或標示待確認，不把不確定資料展示為事實。
- 地圖只供尋找位置，不能取代電話確認或獸醫判斷。
- `data/taichungCoordinateReview.json` 保存 2026-10-08 查核回應與異常註記，僅供維護，不在 App 中載入；更新座標前先核對快取與官方地址。

## 使用情境

- 就醫紀錄表單可開啟地圖並將選取的醫院名稱帶回原表單，保留已填欄位、編輯或複製新增參數，不另外建立一張空白表單。
- 使用者可拒絕定位，仍能搜尋並瀏覽名單；同意後依直線距離排序，並非實際車程。定位取得位置最多等待 12 秒，離開頁面後不更新畫面。
- 選取醫院後可查看服務資訊、來源、電話及外部導航入口。
- 地圖觸控期間暫停外層捲動，避免拖地圖變成滑整頁；選取列表院所會移到院所資訊卡，待確認位置不顯示假座標。

## 待實機確認

自動測試已涵蓋搜尋、距離排序、待確認位置不產生標記、返回原表單的參數合併、地圖與外層捲動互斥、拒絕定位、定位逾時，以及離開後忽略晚到結果。原生地圖與定位在測試中使用替身，不能據此宣稱以下實機情境已驗證。

- iPhone 上地圖拖曳／縮放與清單捲動是否順暢。
- 首次定位、拒絕權限、定位失敗及背景返回情境。
- 撥號、Apple 地圖導航，以及帶回醫院名稱後原表單欄位仍保留。
- 小螢幕及較大字體下，按鈕與服務資訊是否易讀。
